# ICMJE Disclosure Forms — Instructions

**Study:** GRAD: A Two-Stage Algorithm for Resolving Diagnostic Uncertainty in the Plasma p-Tau217 Gray Zone
**Journal:** Alzheimer's Research & Therapy

---

## What is Required

Each author must individually complete and sign an ICMJE Conflict of Interest disclosure form. The journal cannot accept a single form covering all authors.

**Official form:** https://www.icmje.org/disclosure-of-interest/

---

## Instructions for Each Author

1. Go to https://www.icmje.org/disclosure-of-interest/
2. Fill in the online form with your name and the manuscript title
3. Answer all sections:

### Section 1: Grants and Contracts
- Report any grants or contracts from any entity related to the submitted work (past 36 months)
- If none, check "No"

### Section 2: Royalties or Licenses
- Report any royalties or licenses from any entity related to the submitted work
- If none, check "No"

### Section 3: Consulting Fees
- Report any consulting fees from any entity related to the submitted work
- If none, check "No"

### Section 4: Payment or Honoraria
- Report any payment or honoraria for lectures, presentations, manuscripts, or educational events
- If none, check "No"

### Section 5: Support for Attending Meetings
- Report any support for attending meetings from any entity
- If none, check "No"

### Section 6: Patents
- Report any patents planned, pending, or issued
- If none, check "No"

### Section 7: Participation on Advisory Boards
- Report participation on data safety monitoring boards, advisory boards, or similar
- If none, check "No"

### Section 8: Leadership or Fiduciary Roles
- Report any leadership or fiduciary roles in other entities
- **Note:** If an author holds a position at Syntropi AI, this should be disclosed here

### Section 9: Stock or Stock Options
- Report any stock or stock options in entities related to the submitted work
- **Note:** Any equity in Syntropi AI should be disclosed here

### Section 10: Other Financial or Non-Financial Interests
- Report any other relationships or activities that readers could perceive as having influenced the work
- If none, check "No"

4. Download the completed PDF
5. Send to the corresponding author (Brandon Frank) for compilation

## Note on Syntropi AI

If Syntropi AI is a for-profit entity, all authors affiliated with it should disclose:
- Their role (Section 8: Leadership/Fiduciary)
- Any equity/stock (Section 9)
- The company's relationship to the submitted work (Section 10)

If Syntropi AI is a non-profit research group with no commercial interests, authors should still disclose the affiliation but can note "no financial interests" in the relevant sections.

Transparency is key — disclose everything and let the editor assess relevance.
